03 / 人とAIの役割 HUMAN × AI

目標は「全自動」ではない。任せる範囲を設計する。

AIを使う。しかし、目的・責任・承認を人間から消さない。業務ごとの工程は変わっても、人間が境界を決め、AIの仕事を検証し、最後に判断する。

全自動モデル

AIに全部やらせる

  1. AIが考える
  2. AIが作る
  3. AIが公開する
  4. 人間は結果を見る
→
LFモデル

人間が任せ方を決める

  1. 人間が目的と境界を決める
  2. AIへ担当を委譲する
  3. 契約とGateで検査する
  4. 必要な工程だけ再試行する
  5. 人間がレビュー・承認する
  6. Evidenceを残す
CORE CANDIDATERI間で共通性を検証中のControl Pattern
人間目的 / 境界 / 判断 / 承認

  2. 02AIへ委譲するDelegation / Handoff
  3. 03業務を実行するTask / Generation
  4. 04検証・再試行するContract / Gate / Retry
  5. 05人間が判断するReview / Approval / Evidence
