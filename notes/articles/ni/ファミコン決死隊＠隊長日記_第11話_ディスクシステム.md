# 第十一話 ～ディスクシステム～

**1998年β月10日**

「famicom」――そのまんまやないかい！！

Nesticleという、いかにも海外ソフトらしい名前の次に現れたのが「famicom」である。ファミコンを動かすからfamicom。何のひねりもない。だが、Nesticleの毛の生えたケツアイコンで一度心を折られた直後のワシには、この直球さが妙に頼もしく見えた。 特集ページを開くと、いきなり妙に格好いい一文が目に入った。

**「東のNesticle、西のfamicom。」**

何だそれ。横綱か。剣豪か。とにかく凄いらしい。 ただしワシは、まだNesticleでゲームを一本も動かしていない。青い画面は見た。Load ROMも押した。そして落ちた。再起動して、また落ちた。 なので「東のNesticle」と言われても、ワシの知っているNesticleは、**Load ROMを押すと消えるケツ**である。 それでもページを読み進める。第九話の失敗で、ワシもほんの少しだけ慎重になっていた。「最強」と書いてあるだけでは、もう全面的には信用しない。 少しだけである。 そして、その途中だった。

**「ディスクシステムをサポートしているフリーのエミュレータは“famicom”だけです！」**

目が止まった。

ディスクシステム。

この言葉は強かった。サウンド対応だのジョイスティック対応だの、そんな比較は一瞬でどうでもよくなった。

**ディスクシステムが動く。**

それだけで、ワシにとってfamicomを試す理由は十分だった。 今の若い世代には伝わりにくいかもしれないが、当時のディスクシステムは妙に未来っぽい機械だった。カセットではない。ディスクである。しかも書き換えができる。 店へディスクを持っていく。書き換えてもらう。すると昨日まで別のゲームだったディスクが、今日から新しいゲームになる。 子供の目には、**「ゲームが生まれ変わる仕組み」**くらいに見えた。書き換えという行為そのものがイベントだった。店へ行く。何にするか迷う。ディスクを預ける。そして戻ってきた時には、同じ黄色い板の中身が別のゲームになっている。今のダウンロード販売とは違って、手元の“物”が変身する感覚があった。

ワシもかなり遊んだ。ゼルダの伝説、メトロイド、パルテナの鏡、新・鬼ヶ島、ファミコン探偵倶楽部。今でもタイトルを見るだけで、当時の画面や音が一緒に蘇ってくる。ディスクを入れて待つ時間や、独特のロード感まで含めて一つの記憶になっている。

カセットとは少し違う。ディスクシステムには、どこか“機械を動かしている”感じがあった。子供だったワシには、その面倒くささすら格好よく見えていた。

今から思えば、あの仕組みはかなり特殊だった。ゲームを買うというより、媒体を持っていて、その中身を書き換えて遊ぶ。一本の物理メディアが、何度も別の作品へ姿を変える。今ならデジタル配信の方が圧倒的に便利だが、当時は“同じディスクが別のゲームになる”という変化そのものに魔法みたいな面白さがあった。

しかも、何を遊んだかという記憶と、どこで書き換えたかという記憶が一緒になっている。ゲーム単体ではなく、店へ行ったこと、ディスクを持って待ったこと、その日の帰り道までまとめて一つの思い出になっている。だからディスクシステムという言葉を見ただけで、単なるハード名以上のものが一気に戻ってきた。

原本ではタイトルを一つ一つ並べてはいない。ただ、**「ディスクシステムの良作の多さは周知の事実」**と書いている。それだけで説明になっていたのだと思う。 ただし、ワシとディスクシステムの思い出は美しいものばかりではない。 むしろ強烈に残っているのは、**壊れた記憶**である。 一回目。壊れた。修理。 二回目。また壊れた。修理。 三回目。さらに壊れた。修理。

三回も壊すと、さすがに愛着より疲労が勝ってくる。遊びたい時に遊べない。直して戻ってきても、また壊れるかもしれない。ゲーム機なのに、いつの間にか遊ぶ前に機嫌を伺う機械になっていた。

そして三回目の修理の時、店員から言われた。

**「買った方が安いですよ。」**

正論だった。 完全に正論だった。 修理代を積み重ねるくらいなら、新しい本体を買った方が安い。ワシもたぶん分かっていた。 だが、何故か買い替えなかった。 そのままディスクシステムは現役を退いた。 今考えても不思議である。何度も壊れて嫌になったのか、別のゲームへ気持ちが移っていたのか。理由はもう覚えていない。 ただ一つだけ残った。

**「あの時、買っておけばよかった。」**

という後悔である。

ゲーム機というのは、壊れた瞬間に本体だけが消えるわけではない。そこに紐づいていた遊び方や思い出まで、一緒に遠ざかる。当時はそんな大げさなことを考えていなかったが、後になってから効いてくる。

「あれ、もう遊べないんだ。」

そう気付いた時には遅い。だからこそ、何年も経ってから別の形で“戻れる道”を見つけると、人間は必要以上に反応する。ワシにとってfamicomのディスク対応は、まさにそれだった。 だから1998年になって、パソコンの画面で「ディスクシステム対応」という文字を見た時、そこには単なる機能以上の意味があった。

これは“新しい機能を試す”というより、止まったままの時間へ別の入口から戻る感覚に近い。壊れた実機を直すわけではない。新品を買うわけでもない。それでも、あの頃のゲームがもう一度動くかもしれない。そんな発想そのものが、当時のワシには新鮮だった。

エミュレータという技術が面白かったのは、単に古いゲームをPCで動かせるからだけではない。ハードが手元から消えても、別の機械の上で“あの環境”へ近づける。技術が過去を保存する道具にもなり得る。その意味を、この時のワシは言葉には出来ていなかったが、感覚としてはもう掴み始めていたのだと思う。 「また遊べるかもしれない。」 実機では終わってしまった世界が、別の形で戻ってくるかもしれない。 「……ってことは、ワシはコレじゃん！」 原本のワシも、ほぼ同じことを言っている。 Nesticleとfamicom、どちらが速いとか、どちらが有名とか、そんな比較はどうでもよくなった。 ワシには**ディスクシステム**がある。 その一点で決まりだった。 道具選びというのは案外こういうものかもしれない。全部の性能を比較して最適解を出すより、「これができる」が一つ刺されば、それで決まる。

今のAIツールだって似ている。最も賢いか、最も速いかより、**自分がやりたい一つのことができるか。** そこが決定打になることがある。 1998年のワシにとって、その一つがディスクシステムだった。 さらにページを読み進めると、今度はバージョンの話が出てきた。

**「現在のバージョンは4です」**

Version 1。 Version 2。 Version 3。 Version 4。 普通なら最新版の4だけ落とせばよさそうに見える。だが説明によると、Version 1だけ独自形式を持っていて、Version 2から4までは共通形式で改良されてきたらしい。

らしい。

重要なので言っておく。

**ワシは理解していない。**

フォーマット。互換性。バージョン。説明を読みながら「ふむふむ」と頷いているが、頭の中では、 「何か1だけ違うらしい。」 その程度である。 今なら仕様を調べる。FAQを見る。AIに「Version 1と4の違いは？」と聞けばいい。 だが当時のワシには、そこまで整理してくれる相手はいない。 そこで考えた。 Version 1だけ違う。 Version 4が最新版。 ならば。

**両方取ればいい。**

理解を放棄した瞬間である。 だが強い。 分からないなら確保する。考えるのは後。必要かどうかも後。 Version 1。ダウンロード。 Version 4。ダウンロード。 両方確保。 これで安心である。 たぶん。 当時は、後から同じファイルが手に入る保証もなかった。ページが消える。リンクが切れる。作者サイトがなくなる。旧版が消える。 だから、**今あるなら取っておく。** という判断は今よりずっと自然だった。 ただし、その間も電話回線はつながっている。 通信ランプが点滅する。 そして電話代も増える。 当時のインターネットは、見ているだけで金が減る世界でもあった。接続時間には常に薄い緊張感があった。長く見れば見るほど、後で電話代という現実がやって来る。

だから本来なら、必要なファイルを落としたらすぐ切断する。長い説明文は保存して、あとでオフラインで読む。そんな節約が当たり前だった。今みたいに“つなぎっぱなし”が前提ではない。ネットを見るという行為には、常に時計と料金の気配がついて回った。

それでも面白いものを見つけると切れない。あと一個だけ。もう一ページだけ。次のリンクだけ。そうやって数分が増え、数十分が増える。今の無限スクロールとは仕組みが違うが、人間の“もう少しだけ”は昔から変わっていない。

それでもこの日は止まらなかった。数ヶ月前、パソファミに失望した。

数時間前、Nesticleを「最強」と信じ、Load ROMを押した瞬間に落ちた。 そして今、三つ目の本体――**famicom。** しかもディスクシステム対応。 期待するなと言う方が無理である。 Version 1とVersion 4。二つのファイルが揃った。 あとは起動するだけ。 ワシは画面を見つめた。

**「今度はちゃんと動いてくれよ……。」**

原本の最後にも、この言葉が残っている。 第八話のワシなら、ここで「勝った！」くらい言っていたかもしれない。だがNesticleで一度痛い目を見た。ほんの少しだけ慎重になった。

これは小さいけれど、確かな変化だった。最初の頃のワシは、“見つけた＝勝ち”だった。今は、“見つけた。では動かしてみよう。”になっている。失敗すると、人間は少しだけ賢くなる。少しだけである。

そして面白いのは、失敗を重ねるほど探索をやめるどころか、逆に深く入っていることだった。パソファミで終わるはずだった。Nesticleでまた止まるはずだった。それなのに今、Version 1と4を両方持って次の実験へ向かっている。後から考えると、このしつこさこそが“決死隊”へ続いていったのだと思う。

期待はしている。ものすごくしている。だが今回は、勝利宣言ではなく祈りだった。

頼む。

動いてくれ。 ファミコンを。 そしてできるなら。 三回壊れて終わった、あのディスクシステムを。 もう一度見せてくれ。 ダウンロード完了。 Version 1。 Version 4。 ワシは二つのファイルを眺めた。 今度こそ。 ……いや。 まだ油断するな。 そう思いながらも、頭の中にはもうディスクシステムのゲーム画面が浮かんでいた。 結局、隊長は隊長である。 マウスを握る。 そして。

運命の導入実験へ。
