# notes/

ここは Project Documentation ではない。

ここは**開発現場**である。

docs/ に残るのは「決まったこと」。 notes/
に残るのは「決まるまでの戦い」。

ここには遠慮なく書く。

-   バグを見つけた瞬間
-   AIが暴走した瞬間
-   「これ記事になるｗ」と笑った瞬間
-   Root Cause
-   次の一手

育ったものだけが docs/ へ昇格する。

このフォルダは、Foundryの文化を残すために存在する。
