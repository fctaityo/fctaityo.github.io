v4.0で確立したHuman-Directed FoundryのVisual Storyを維持したまま、Human × AIの責務表現をCurrent Architectureへ同期し、FOUNDRY PULSEと来訪者カウンターを追加しました。

Why Changed

v4.0のHuman × AI節では、RI#1 Article Production固有の7工程がLocal AI Foundry全体の標準Workflowのように見える余地がありました。v4.1では、Project全体では業務非依存のControl Patternを示し、7-stage Article Production WorkflowはRI#1固有の実装例として所属を明確化しました。

What Changed

Human × AI Responsibility

目的・境界・判断・承認をHumanに残し、Delegation、Validation、Retry、Review、Evidenceへつなぐ業務非依存のControl Patternへ整理。

RI#1 Seven-stage Ownership

企画・調査・執筆・確認・画像・監査・保存の7工程をRI#1 Article Production固有の実装例として明示。

FOUNDRY PULSE

Public StatusからProject State、Runtime、Acceptance、Snapshot更新日を取得し、Foundry全体の現在地を小型管制盤として表示。

Visitor Counter

公式Host上だけで有効になる軽量Public Counterを追加。同一ブラウザではJST基準で1日1回だけ加算。

Parallel Project View Preserved

既存のRI#1 / RI#2 / WEB / CORE / RI#3進行ボードは変更せず、その役割を維持。

Responsive Composition

Human × AI節を広幅・中幅・Mobileの3段階で再構成し、横スクロールを抑制。

Counter Semantics

  • 本番Host `fctaityo.github.io` でのみCounterAPI v1を使用する。
  • 同一ブラウザではJSTの日付単位で1回だけ加算する。
  • 別ブラウザ、別端末、localStorage削除等は別カウントになる可能性がある。
  • 厳密なUnique User Analyticsではなく、Website上の軽量な来訪カウンターとして扱う。

Preserved

  • v4.0のHero、Brand Identity、Visual Story
  • 既存の並行プロジェクトPhase Graph
  • Public Documentationへの導線
  • Project StateとRuntime Acceptanceを混同しない表示
  • Foundry Coreを確定済みとして扱わない境界

Verification Scope

  • Human × AI責務境界とRI#1 7工程の所属
  • Desktop / Narrow Desktop / Mobile Responsive Layout
  • FOUNDRY PULSE Static Fallback / Public Status Sync
  • Visitor Counter Local Disable / Live Host Enable
  • JST日付キーによる1日1回判定
  • 既存Parallel Project View保持
  • Internal Anchor / Public Documentation / Release links
