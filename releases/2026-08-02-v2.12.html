Local AI Foundry
v2.12

Project StateとActive Workを別責務として表示し、公式HPを「AIチームを作る基盤」から「AIチームを運用し続ける基盤」へ更新しました。

WHY CHANGED

Project State Current Snapshotだけでは、Documentation IA実装の完了Checkpointと再開地点を確認できませんでした。そこでActive Work Current Snapshotを導入し、現在地と作業地点を分けて表示します。

v2.12 更新内容

  • Heroへ継続運用の責務を追加AIチームを動かすだけでなく、変更・検証・承認・公開まで壊さず運用し続ける生産基盤であることを明示しました。
  • Foundry Operating Principleを追加既存8 Design Principlesを維持したまま、Project運営思想として「管理のための管理はしない。必要になったら育てる。」を別枠で追加しました。
  • Knowledgeの現在地を二つへ分離Project全体の正式状態を示すProject Stateと、現在作業中の復帰地点を示すActive Workを別Snapshotとして案内しました。
  • 現在地表示を3つの責務へ再設計Project State、Current Initiative、Next Gateを分け、正式状態・作業地点・次の判断を混在させない表示へ変更しました。
  • Documentation IA導線を強化Documentation Information Architectureを構造の正本として明示し、Public Documentationの入口からInformation Architectureへ辿れる説明へ更新しました。
  • ReleaseへWhy Changedを追加何を変更したかだけでなく、なぜ変更が必要だったのかをトップページとReleaseページへ記録しました。
  • Roadmapを実装状態へ同期Writing、Review、Image、Final Auditを未実装・計画中としていた旧表示を修正し、Published Workflow、次のGateであるRuntime Verification、将来拡張を分けて表示しました。
  • 既存機能と構造を維持AIチーム説明、固定シナリオデモ、システム構成、7段Workflow、JavaScript挙動は変更していません。
